# WORLD AI FACTORY v0.1

Independent static, offline-capable prototype. Open `index.html` on a browser, enter company name, choose trade/restaurant/delivery and language (JA/EN/KM), click Generate, then save generated `company-ai-demo.html`.

**Important:** Generates *static sales demo websites only*. Does not create functional AI, backends, payments, order submission, license verification, or production systems. No network calls. Does not touch existing repositories. WORLD TRADE AI's locked brand/UX is not yet incorporated as a dedicated template; do not represent the generic trade output as compliant with the locked blueprint.

To publish: create a new `world-ai-factory` GitHub repository and upload `index.html` at root. GitHub Pages can serve it as a static site. No paid services required for local usage.

Next: locked per-industry templates, schema validation, automated checks, versioned artifact packages, preview tests, then opt-in deployment integrations.
